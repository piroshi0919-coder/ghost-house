# Chat QuickLink

シンプルなチャット型Webアプリのサンプルです。チャットで特定のワード（例: `help`, `docs`, `pricing`）を送ると、サーバーがURLをレスポンスしてリンクを表示します。

使い方（Windows PowerShell）:

```powershell
# 1) 依存パッケージをインストール
npm install

# 2) サーバーを起動
npm start

# 3) ブラウザで開く
# http://localhost:3000 にアクセス
```

カスタマイズ:
- トリガー単語とリンクは `server.js` の `triggers` オブジェクトで変更できます。

PDF表示について:
- キーワードが3つ以上マッチした場合、サーバーはワークスペース内の `current_newsparer/第一幽霊の過去.pdf` を返すように設定されています。
- ブラウザで表示されるリンクをクリックすると、PDFが開きます（ローカル実行時は `http://localhost:3000/files/第一幽霊の過去.pdf`）。
キーワード要件:
- このアプリはデフォルトで「メッセージに少なくとも3つのキーワードが含まれている場合のみ関連リンクを表示」するようになっています。
- `server.js` の `triggers` にキーワードを増やしておくと、ユーザーが3つ以上含めた場合にその関連URLを複数返します。

注意:
- インターネットにある URL を指定していますが、ここは自分のドメインや社内ドキュメントへ変更してください。

ローカルで使う場合（シンプル）

1) 依存パッケージをインストール
```powershell
npm install
```

2) サーバーを起動
```powershell
npm start
```

3) ブラウザで開く
```text
http://localhost:3000
```

カスタマイズ:
- トリガー単語とリンクは `server.js` の `triggers` オブジェクトで変更できます。

注意:
- このビルドはローカル利用向けに QR と公開URL 機能を削除してあります。共有や公開が必要になったら、再度その機能を追加することは可能です。
